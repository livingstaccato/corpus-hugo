---
title: Front Matter Reference
summary: Every field single.html and list.html read from a page.
weight: 2
---

| Field | Where it shows |
| --- | --- |
| `summary` / `description` | Card subtitle, page lede |
| `tags` | Hugo's built-in taxonomy pages |
| `weight` | Order in the section tree and card grid |
| `related` | The "Related" list — bare slugs resolve in any section |
| `sources` | The "Sources" list |
| `references` | The "References" list, one `URL label text` per line |
| `created` / `updated` | The source-meta strip (falls back to git info) |
| `source_path` | "Edit on GitHub" link — needs `site.Params.github` set too |
